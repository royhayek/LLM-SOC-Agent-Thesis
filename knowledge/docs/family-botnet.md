# Attack family: Botnet traffic

Botnet traffic (botnet). An IoT device D, acting as a botnet member: botnet traffic is sent from D to an external host (not a testbed device, the broker or the honeypot), so D is the only testbed device in the traffic (Annex C ASSUMPTION 5).

ATT&CK technique: T1584.005 — Compromise Infrastructure: Botnet.
