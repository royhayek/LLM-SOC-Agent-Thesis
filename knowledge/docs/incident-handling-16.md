# Incident-handling guidance (A1)

> si la bande passante des liens réseau fournis par les opérateurs est saturée, ceux-ci doivent être contactés afin de filtrer le trafic.
>
> (English: if the bandwidth of the network links supplied by the operators is saturated, they must be contacted to filter the traffic.)
