# Technique T1046: Network Service Discovery

Adversaries enumerate services running on remote hosts and network infrastructure — for example with port scans — to find potential targets for later exploitation.

Generic ATT&CK mitigations for this technique: M1042 (Disable or Remove Feature or Program), M1031 (Network Intrusion Prevention), M1030 (Network Segmentation).
