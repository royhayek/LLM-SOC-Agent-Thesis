# Incident-handling guidance (A5)

> si une adresse IP est identifiée comme étant malveillante, il sera possible de mettre en place une règle au niveau des pare-feux.
>
> (English: if an IP address is identified as malicious, it will be possible to put a rule in place at the firewalls.)
