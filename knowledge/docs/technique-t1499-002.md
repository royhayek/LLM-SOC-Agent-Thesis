# Technique T1499.002: Endpoint Denial of Service: Service Exhaustion Flood

Adversaries overwhelm a network service (such as a web or messaging service) with a high volume of requests, exhausting the CPU or memory that serves it.

Generic ATT&CK mitigations for this technique: M1037 (Filter Network Traffic).
