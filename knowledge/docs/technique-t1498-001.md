# Technique T1498.001: Network Denial of Service: Direct Network Flood

Adversaries flood a target directly with high-volume traffic (often from a botnet) to saturate its network capacity and degrade availability.

Generic ATT&CK mitigations for this technique: M1037 (Filter Network Traffic).
