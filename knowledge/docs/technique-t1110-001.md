# Technique T1110.001: Brute Force: Password Guessing

Adversaries guess login credentials without prior knowledge of them, typically using a list of common or likely passwords against a service such as SSH.

Generic ATT&CK mitigations for this technique: M1036 (Account Use Policies), M1032 (Multi-factor Authentication), M1027 (Password Policies), M1051 (Update Software), M1018 (User Account Management).
