# Technique T1498: Network Denial of Service

Adversaries exhaust a target's network bandwidth by directing high-volume traffic at a resource or the infrastructure it depends on, blocking availability to users.

Generic ATT&CK mitigations for this technique: M1037 (Filter Network Traffic).
