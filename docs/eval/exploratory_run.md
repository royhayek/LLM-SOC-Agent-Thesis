## Bugs found and fixed

The exploratory run surfaced, in order:
1. **Native crash on model load** (OpenMP/threading on 16 GB): fixed by loading the KB model once in the main thread + `TOKENIZERS_PARALLELISM`/`OMP_NUM_THREADS` (PR #95, #97).
2. **A single over-ceiling output aborted the whole run**: the runner now absorbs per-item failures as unusable verdicts (PR #95).
3. **Output truncated at the 250-token ceiling** (visible reasoning under json_object): ceiling raised to 768 (METHODS changelog 19, PR #94).
4. **Node parse failures crashed the run**: absorbed as unusable verdicts (PR #98).
5. **Dominant failure: the model wraps its JSON in markdown/code fences** so strict `model_validate_json` failed: parse by JSON extraction (METHODS changelog 20, PR #101). This recovered C5 96.8%→1.6% and Baseline B 93.5%→4.8% unusable.

Residual (not a pipeline bug): single sparse-source conditions C2 (flows) and C4 (honeypot) stay high, driven by empty or invented `evidence_ids` — a real single-source grounding effect, relevant to H1.
