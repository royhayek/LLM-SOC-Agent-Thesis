## Decisions (E3-09, METHODS.md changelog 16)

- **ssh_brute_force / port_scan below the 50 target.** These honeypot/scan families are bursty, so most of their labelled windows hold no alert and are dropped at assembly. The corpus is frozen as-is; the thesis reports reduced per-family H1 power for them.
- **Benign split.** The post-attack benign blocks captured no telemetry, so benign bundles are split by a fixed-seed per-bundle 70/30 rule, not by block (§4.3 treats each benign bundle as its own bootstrap block, so this leaks nothing across sets).
